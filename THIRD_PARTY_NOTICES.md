The external baseline is [DeepSeek Harness Team's dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype/tree/8c32a9dc5d72c033816c6a8110b37f40cf94fba4), pinned at that commit and installed locally under `third_party/dsh-superagent-prototype/`. ## Distribution boundary

Preserve upstream LICENSE/NOTICE files in locally downloaded repositories. Dependencies installed by pip or pnpm retain their own terms; ClonAct's license is not a substitute for their notices. Bundling dependencies or redistributing containers requires reviewing those artifacts separately.

Do not publish generated benchmark JSONL, locally materialized upstream/gold patches (`synaptic_stream_60/data/gold/`, `synaptic_stream_60/data/swe_patches/`), protected AppWorld code/data, runtime workspaces, raw traces, or archived research records as MIT-only assets. AppWorld's protected material and derivatives must remain encrypted for public redistribution under its stated terms. Local reconstruction changes what this project distributes; it does not waive upstream terms.

The separate private research Git history contains third-party-derived task payloads. Removing current files does not remove historical copies. This source repository was prepared from the reviewed allowlist with a fresh Git history. Future updates must preserve that boundary and must not import private research branches or tags.
